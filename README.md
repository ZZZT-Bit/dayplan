根据每周大学课表自动规划一天的时间，并在该动的时候提醒你。纯静态网页，装到手机主屏幕后就是一个独立 App。
## 它做什么
1. **录一次周课表**（周一至周日各不相同），手动填或从教务系统批量粘贴
2. **自动排剩下时间**：起床先吃早饭 → 上午放最难的新内容 → 午饭后歇 25 分钟 → 下午刷题 → 18 点后只复习 → 睡前 1 小时不排学习
3. **提醒**：页面开着时应用内全屏响铃；导进手机日历后由系统准时提醒

## 装到手机

用手机浏览器打开上面的 `https://` 地址：

- **iPhone（Safari）**：底部「分享」→「添加到主屏幕」
- **安卓（Chrome）**：右上「⋮」→「安装应用」/「添加到主屏幕」

装好后是独立图标、全屏无地址栏、**断网也能打开**（Service Worker 已缓存）。

## 第一次用要做的两件事

1. 进「课表」页，把示例课表换成你自己的 —— 页面顶部有黄条提醒
2. 回「今天」页，点「导出整周」→ 把 `.ics` 导进手机日历 → 之后到点手机会响

## 关于提醒的边界

| 场景 | 能否提醒 |
|---|---|
| App 开着 / 刚切到后台 | ✅ 应用内响铃 + 震动 |
| App 已关闭 | ❌ 浏览器不允许，**这是系统限制** |
| 已导入系统日历 | ✅ 手机自己提醒，飞行模式也响 |

想让手机在 App 关掉时也准时叫住你，**只有导入日历这一条路**。

## 数据在哪

全部存在你手机浏览器的 localStorage，不上传任何服务器。换手机或清浏览器数据前，先到「设置」→「导出备份」存一份 JSON。
## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（HTML/CSS/JS 单文件） |
| `manifest.json` | PWA 清单，决定装到主屏后的名字和图标 |
| `sw.js` | Service Worker，负责离线缓存 |
| `icons/` | 应用图标（192/512，含 maskable 与 iOS 版本） |
| `serve.js` | 仅本地预览用，部署不需要 |
